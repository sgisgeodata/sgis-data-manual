## 지자체 연구소 공간분석 교육

### 실습 준비사항

실습을 위한 프로그램과 실습용 자료는 전산교육실 PC에 준비됩니다.
개인 노트북을 준비하거나 별도 실습을 위한 실습 준비사항을 안내해드립니다.

#### QGIS 설치
[QGIS 다운로드 사이트](https://qgis.org/download/)에서 QGIS LTR(장기관리버전) 3.44를 내려받아서 설치해주세요.

#### R Studio 설치
R, R Studio, RTools를 기본 옵션으로 차례대로 설치해주세요.
[R-4.4.3](https://cran.r-project.org/bin/windows/base/old/4.4.3/R-4.4.3-win.exe)을 내려받아서 설치합니다.
R-4.6.1 버전이 최신 버전이지만 시각화 패키지 연동이 안정적인 4.4.3버전으로 실습하겠습니다.
[R Studio 다운로드 사이트](https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads)에서 Windows 11용 최신 버전을 설치합니다.
[RTools 4.4](https://cran.r-project.org/bin/windows/Rtools/rtools44/rtools.html)를 내려받아서 설치합니다.
