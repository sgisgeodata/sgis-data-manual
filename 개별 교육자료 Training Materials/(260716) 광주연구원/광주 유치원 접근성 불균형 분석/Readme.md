# 광주 광산구 유치원 도보 접근성 및 사각지대 분석

## 분석 개요

광주연구원의 「시민 수요 기반의 광주형 N분 도시 생활서비스시설 배치 전략」에서는 주요 생활서비스시설의 접근성을 비교한 결과, 유치원의 공간적 불균형이 상대적으로 크게 나타났으며 광산구의 접근 취약성이 두드러지는 것으로 분석되었습니다.

이에 본 분석에서는 광산구 내 유치원을 대상으로 ORS 기반 도보 10분 접근권역을 구축하고, 인구격자와 행정동 데이터를 결합하여 유치원 서비스 사각지대와 미도달 인구를 파악하였습니다. 이를 통해 유치원 접근성이 취약한 지역을 확인하고 향후 보육시설 배치 및 지원정책의 기초자료를 마련하고자 하였습니다.

## 사용 데이터

| 데이터 | 출처 및 형태 |
|:---|:---|
| 유치원 위치 정보 | 유치원 위치정보 SHP |
| 광주 100m 총인구 격자 | SGIS 통계지리정보서비스 |
| 광주 1km 9세 이하 인구 격자 | SGIS 통계지리정보서비스 |
| 광산구 행정동 경계 | SGIS 통계지리정보서비스 SHP |
| 도보 도로망 | ORS(OpenRouteService) |

## 분석 과정

① **분석 대상 구축**  
광산구 경계 내 유치원 위치를 추출하고 공간적 분포를 확인하였습니다.

② **도보 접근권역 생성**  
ORS를 활용하여 유치원별 도보 10분 접근권역을 생성하였습니다.

③ **서비스 사각지대 추출**  
도보권과 인구격자를 중첩하여 유치원 도보권 밖에 위치한 격자를 분류하였습니다.

④ **행정동별 인구 집계**  
공간 조인을 통해 행정동별 전체 인구와 미도달 인구를 합산하였습니다.

⑤ **접근성 불균형 시각화**  
행정동별 미도달 인구수와 전체 인구 대비 미도달 인구 비율을 산출하여 단계구분도로 표현하였습니다.
