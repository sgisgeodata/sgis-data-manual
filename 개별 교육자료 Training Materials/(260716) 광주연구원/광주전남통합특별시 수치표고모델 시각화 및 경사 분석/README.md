# 광주광역시 90m DEM 기반 3D 지형 및 급경사지 시각화 분석 (R)

## 분석 개요

본 분석은 한반도 90m 수치표고모형(DEM)과 광주광역시 시군구 행정경계 데이터를 활용하여 광주광역시의 지형 고저 차이와 급경사지의 하향 흐름 방향을 3차원으로 시각화한 분석입니다.

전국 범위의 DEM에서 광주광역시 5개 구에 해당하는 영역만 추출한 뒤, 표고값을 이용하여 입체적인 3D 지형을 생성했습니다.

또한 각 DEM 격자에서 주변 8개 격자를 비교하여 가장 급하게 낮아지는 방향을 계산하고, 일정 경사각 이상의 하향 방향을 3D 화살표로 표시했습니다.

최종 결과물은 확대·축소, 회전, 기울기 조절이 가능한 deck.gl 기반의 HTML 지도로 제작했습니다.

## 분석 과정

### 1. DEM 및 행정경계 데이터 불러오기

먼저 `terra` 패키지의 `rast()` 함수를 이용하여 한반도 90m DEM을 불러왔습니다.

전국 시군구 행정경계는 `sf` 패키지의 `st_read()` 함수를 이용하여 읽었습니다.

행정경계 데이터에 포함된 한글 속성값이 깨지는 현상을 줄이기 위해 CP949 인코딩 옵션을 적용했습니다.

```r
dem <- rast(dem_file)

sigungu <- st_read(
  sigungu_file,
  options = "ENCODING=CP949",
  quiet = TRUE
)
```

DEM과 행정경계의 좌표계 및 컬럼명을 확인하여 이후 공간 연산이 정상적으로 수행될 수 있도록 구성했습니다.

### 2. 광주광역시 5개 구 추출

전국 시군구 경계에서 `SIGUNGU_CD` 값을 기준으로 광주광역시의 5개 자치구만 선택했습니다.

| 시군구 코드 | 자치구 |
| -----: | --- |
|  24010 | 동구  |
|  24020 | 서구  |
|  24030 | 남구  |
|  24040 | 북구  |
|  24050 | 광산구 |

```r
gwangju <- sigungu %>%
  mutate(SIGUNGU_CD = as.character(SIGUNGU_CD)) %>%
  filter(
    SIGUNGU_CD %in%
      c("24010", "24020", "24030", "24040", "24050")
  )
```

추출된 행정경계는 `st_make_valid()`를 이용하여 유효한 공간도형으로 보정하고, DEM과 동일한 좌표계로 변환했습니다.

DEM 자르기와 표고값 추출 등의 공간 연산은 두 자료의 좌표계가 일치해야 정확하게 수행됩니다.

### 3. 광주광역시 경계 기준 DEM 자르기

전국 범위의 DEM에서 광주광역시 영역만 남기기 위해 `crop()`과 `mask()`를 순서대로 적용했습니다.

```r
dem_gwangju <- dem %>%
  crop(gwangju_vect) %>%
  mask(gwangju_vect)
```

* `crop()`은 광주광역시 경계의 최소 사각 범위로 DEM을 자릅니다.
* `mask()`는 사각 범위 안에서도 광주광역시 경계 바깥에 위치한 셀을 제거합니다.

이후 표고값이 `-100m`보다 낮은 셀은 비정상값 또는 분석에 불필요한 값으로 판단하여 `NA`로 처리했습니다.

```r
dem_gwangju[dem_gwangju < -100] <- NA
```

### 4. 3D 시각화를 위한 DEM 해상도 조정

원본 DEM의 셀 수가 많으면 브라우저에서 수천 개 이상의 3D 객체를 동시에 렌더링해야 하므로 지도의 실행 속도가 느려질 수 있습니다.

이를 방지하기 위해 목표 셀 수를 약 12,000개로 설정하고, 셀 수가 기준을 초과할 경우 주변 셀의 평균 표고값을 이용해 DEM을 집계했습니다.

```r
target_cells <- 12000
```

집계 계수는 원본 셀 수와 목표 셀 수를 이용하여 자동으로 계산됩니다.

```r
fact_value <- ceiling(
  sqrt(ncell(dem_gwangju) / target_cells)
)
```

이후 `aggregate()` 함수를 이용하여 여러 개의 원본 셀을 하나의 시각화용 셀로 변환했습니다.

```r
dem_plot <- aggregate(
  dem_gwangju,
  fact = fact_value,
  fun = mean,
  na.rm = TRUE
)
```

원본 자료의 공간해상도는 90m이지만, 최종 지도에서 표현되는 격자의 실제 크기는 계산된 집계 계수에 따라 90m보다 커질 수 있습니다.

이 과정은 원본 DEM 자체를 변경하기 위한 것이 아니라 웹 브라우저에서 원활하게 3D 지형을 표시하기 위한 시각화 최적화 과정입니다.

### 5. DEM 격자의 3D 폴리곤 변환

deck.gl 지도에서 각 DEM 셀을 입체적인 기둥 형태로 표현하기 위해 래스터 셀을 개별 사각형 폴리곤으로 변환했습니다.

```r
dem_poly <- as.polygons(
  dem_plot,
  dissolve = FALSE,
  na.rm = TRUE
)
```

각 셀에는 다음과 같은 값이 포함됩니다.

| 변수       | 설명                    |
| -------- | --------------------- |
| `elev`   | 해당 격자의 평균 표고값         |
| `height` | 높이 과장값이 적용된 3D 시각화 높이 |

3D 지도에서 지형의 고저 차이가 더욱 분명하게 보이도록 실제 표고값에 높이 과장 계수를 적용했습니다.

```r
z_exaggeration <- 3.5
```

```r
dem_poly_sf <- dem_poly_sf %>%
  filter(!is.na(elev)) %>%
  mutate(
    elev = round(elev, 1),
    height = round(elev * z_exaggeration, 1)
  ) %>%
  st_transform(4326)
```

예를 들어 실제 표고가 100m인 격자는 지도에서 `100 × 3.5 = 350`의 시각적 높이로 표현됩니다.

높이 과장은 실제 표고값을 변경하는 것이 아니라 지형의 입체감을 강조하기 위한 시각적 설정입니다.

### 6. 급경사지 하향 방향 계산

급경사지 방향은 각 DEM 셀을 기준으로 주변 8개 셀을 비교하여 계산했습니다.

기준 셀을 A라고 할 때, 주변 셀 중 A보다 표고가 낮은 셀만 하향 이동 후보로 설정했습니다.

각 후보 셀에 대해서는 다음 식을 이용하여 경사각을 계산했습니다.

```text
경사각 = arctan(표고 차이 / 수평거리) × 180 / π
```

직선 방향에 위치한 셀과 대각선 방향에 위치한 셀은 중심점 간 거리가 다르므로 실제 셀 간 수평거리를 각각 계산했습니다.

```r
dist_xy <- sqrt(
  (dc * res_x)^2 +
  (dr * res_y)^2
)

slope_deg <- atan(
  elev_diff / dist_xy
) * 180 / pi
```

각 기준 셀에서는 주변의 낮은 셀 중 가장 큰 경사각을 가지는 하나의 방향만 선택했습니다.

따라서 한 셀에서 여러 개의 화살표가 생성되는 것이 아니라, 가장 급하게 낮아지는 대표 방향 하나만 표시됩니다.

---

### 7. 최소 경사각 기준 적용

모든 하향 방향을 지도에 표시하면 화살표 수가 지나치게 많아질 수 있으므로 최소 경사각 기준을 적용했습니다.

```r
arrow_min_degree <- 15
```

R에서는 경사각이 15도 이상인 화살표 후보를 미리 생성하고, HTML 지도에서는 사용자가 다음 기준 중 하나를 선택할 수 있도록 구성했습니다.

| 선택 기준  | 설명                    |
| ------ | --------------------- |
| 화살표 없음 | 급경사지 방향을 표시하지 않음      |
| 15도 이상 | 경사각이 15도 이상인 하향 방향 표시 |
| 20도 이상 | 경사각이 20도 이상인 하향 방향 표시 |
| 25도 이상 | 경사각이 25도 이상인 하향 방향 표시 |
| 30도 이상 | 경사각이 30도 이상인 하향 방향 표시 |

사용자가 더 높은 경사각을 선택할수록 상대적으로 급한 경사지의 방향만 지도에 남게 됩니다.

### 8. 3D 화살표 생성

급경사지 방향은 높은 셀 A에서 가장 급하게 낮아지는 이웃 셀 B를 향하도록 생성했습니다.

화살표는 다음 두 부분으로 구성됩니다.

* 화살표 몸통
* 좌우 두 개의 선으로 이루어진 화살촉

화살표 시작점은 이웃 셀의 위치에 따라 기준 셀 A의 윗면 모서리 또는 꼭짓점에 배치했습니다.

화살표 끝점은 선택된 낮은 셀 B의 중심점에 배치했습니다.

시작점과 끝점의 높이는 각각의 표고값에 높이 과장 계수를 적용하여 계산했습니다.

```r
z_start <- elev_a * z_exaggeration + arrow_lift
z_tip <- elev_b * z_exaggeration + arrow_lift
```

DEM 표면과 화살표가 같은 높이에 있을 경우 화면에서 겹치거나 깜빡이는 현상이 발생할 수 있으므로, 화살표를 지형 표면보다 약간 위로 띄웠습니다.

```r
arrow_lift <- 4
```

또한 화살표 길이가 짧은 경우 화살촉이 몸통보다 커지는 현상을 방지하기 위해 화살촉의 길이와 폭을 전체 화살표 길이에 맞춰 자동으로 조정했습니다.

### 9. 화살표 중복 제거

화살표 계산 과정에서 시작점과 도착점이 동일한 화살표가 중복으로 만들어질 가능성을 고려하여 중복 제거 과정을 적용했습니다.

시작점과 끝점 좌표를 소수점 셋째 자리까지 반올림한 뒤, 하나의 화살표 식별키를 생성했습니다.

```r
arrow_df <- arrow_df %>%
  mutate(
    arrow_key = paste(
      round(x_start, 3),
      round(y_start, 3),
      round(x_tip, 3),
      round(y_tip, 3),
      sep = "_"
    )
  ) %>%
  distinct(arrow_key, .keep_all = TRUE) %>%
  select(-arrow_key)
```

이를 통해 시작점과 도착점이 완전히 같은 동일 화살표만 제거하고, 서로 다른 위치나 방향을 가진 화살표는 유지했습니다.

### 10. 웹 지도용 좌표계 변환

급경사지 화살표 계산은 DEM의 투영좌표계에서 미터 단위로 수행했습니다.

그러나 deck.gl 웹 지도는 경도와 위도 좌표를 사용하므로, 화살표 시작점·끝점·화살촉 좌표를 EPSG:4326 좌표계로 변환했습니다.

```r
temp_4326 <- st_transform(temp_sf, 4326)
```

변환된 좌표는 deck.gl의 `PathLayer`에서 사용할 수 있도록 JSON 형식으로 구성했습니다.

```r
arrow_json <- toJSON(
  arrow_data,
  auto_unbox = TRUE,
  digits = 8
)
```

### 11. 광주광역시 자치구 경계 표시

광주광역시의 5개 자치구 위치를 쉽게 구분할 수 있도록 행정경계선을 3D 지형 위에 표시했습니다.

각 경계점 위치에서 DEM 표고값을 추출한 뒤, 지형 높이에 맞춰 경계선의 높이를 계산했습니다.

```r
elev_vals <- terra::extract(
  dem_gwangju,
  vect(boundary_pts)
)[, 2]
```

```r
z_vals <- elev_vals *
  z_exaggeration +
  boundary_lift
```

경계선이 3D 지형 내부에 가려지지 않도록 추가 높이 보정값을 적용했습니다.

```r
boundary_lift <- 220
```

최종 지도에서는 동구, 서구, 남구, 북구, 광산구의 경계를 검은색 선으로 확인할 수 있습니다.

### 12. deck.gl 기반 인터랙티브 지도 제작

최종 지도는 JavaScript 기반 공간 시각화 라이브러리인 deck.gl을 활용하여 제작했습니다.

R에서 생성한 DEM GeoJSON, 급경사지 화살표 JSON, 행정경계 JSON을 HTML 내부에 직접 삽입했습니다.

이를 통해 별도의 공간데이터 파일을 불러오지 않아도 HTML 파일 내부의 데이터를 이용하여 지형을 표시할 수 있도록 구성했습니다.

지도에는 다음 레이어가 포함됩니다.

| 레이어            | 설명                           |
| -------------- | ---------------------------- |
| `TileLayer`    | 백지도, 위성지도, 어두운 지도 등의 배경지도 표시 |
| `GeoJsonLayer` | 표고값을 높이로 적용한 3D DEM 격자 표시    |
| `PathLayer`    | 광주광역시 자치구 경계 표시              |
| `PathLayer`    | 급경사지 하향 방향 화살표 몸통 표시         |
| `PathLayer`    | 급경사지 하향 방향 화살촉 표시            |

### DEM 표현 방식 전환

3D 지형은 다음 두 가지 방식으로 표현할 수 있습니다.

* 표고 구간별 다색 지형
* 회색 단색 지형

다색 지형은 실제 표고값에 따라 색상을 구분했습니다.

|           표고 구간 | 지도 표현    |
| --------------: | -------- |
|          50m 미만 | 녹색 계열    |
|  50m 이상 100m 미만 | 연두색 계열   |
| 100m 이상 200m 미만 | 황색 계열    |
| 200m 이상 350m 미만 | 갈색 계열    |
| 350m 이상 550m 미만 | 진한 갈색 계열 |
|         550m 이상 | 밝은 회색 계열 |

이를 통해 광주광역시의 저지대와 산지·고지대 분포를 직관적으로 확인할 수 있습니다.

### 경사각 기준 선택

사용자는 화살표 표시 기준을 직접 선택할 수 있습니다.

경사각 기준을 높게 설정하면 완만한 경사 방향은 제외되고, 상대적으로 급한 경사지의 하향 방향만 표시됩니다.

이를 통해 특정 경사 수준 이상의 지역을 선택적으로 확인할 수 있습니다.

## 주요 시각화 설정값

| 설정값                       |    기본값 | 설명                       |
| ------------------------- | -----: | ------------------------ |
| `z_exaggeration`          |    3.5 | 실제 표고값에 적용하는 3D 높이 과장 계수 |
| `target_cells`            | 12,000 | 브라우저에 표시할 목표 DEM 셀 수     |
| `arrow_min_degree`        |     15 | R에서 생성하는 화살표 후보의 최소 경사각  |
| `arrow_head_length_meter` |     32 | 화살촉 길이                   |
| `arrow_head_width_meter`  |     22 | 화살촉 폭                    |
| `arrow_lift`              |      4 | 화살표를 DEM 표면보다 위로 띄우는 높이  |
| `boundary_lift`           |    220 | 행정경계선을 지형 위로 띄우는 높이      |

지도의 실행 속도가 느린 경우 `target_cells` 값을 줄여 표시되는 격자 수를 감소시킬 수 있습니다.

지형의 고저 차이가 지나치게 강조되거나 약하게 보이는 경우 `z_exaggeration` 값을 조정할 수 있습니다.

## 분석 결과

분석 결과, 광주광역시의 지형 고저 차이를 3D 격자 형태로 확인할 수 있었습니다.

표고가 낮은 지역과 높은 산지 지역이 서로 다른 높이와 색상으로 표현되므로 광주광역시 내부의 지형 분포를 직관적으로 파악할 수 있습니다.

또한 각 DEM 셀에서 가장 급하게 낮아지는 방향을 화살표로 표시하여 급경사지의 대표적인 하향 방향을 확인할 수 있도록 구성했습니다.

경사각 기준을 15도, 20도, 25도, 30도로 변경하면 선택한 기준 이상의 경사지만 단계적으로 확인할 수 있습니다.

이를 통해 다음과 같은 공간적 특성을 살펴볼 수 있습니다.

* 광주광역시 내 산지와 고지대 분포
* 저지대와 고지대 사이의 표고 차이
* 급경사지가 집중되는 공간
* 각 급경사지의 대표적인 하향 방향
* 자치구 경계와 지형 분포의 공간적 관계

다만 화살표는 실제 강우 유출이나 토사 이동을 직접 모의한 결과가 아니라, 각 DEM 셀과 주변 8개 셀의 표고 차이를 기준으로 계산한 지형적 하향 방향입니다.

따라서 실제 사면재해나 유출 경로 분석에 활용하려면 강우량, 지질, 토양, 토지피복, 배수체계 등의 추가 자료를 함께 고려해야 합니다.

## 분석 의의

본 분석은 광주광역시의 지형을 단순한 2차원 고도 지도가 아닌 3차원 형태로 표현하여 지역 내 산지와 고지대의 분포를 직관적으로 확인하기 위해 수행되었습니다.

DEM 격자별 표고값을 3D 높이로 변환하고 행정경계를 함께 표시함으로써 각 자치구의 지형적 특성을 공간적으로 비교할 수 있습니다.

또한 각 격자에서 가장 급하게 낮아지는 방향을 계산하여 일정 경사각 이상의 지역을 화살표로 표현함으로써 급경사지의 위치뿐만 아니라 대표적인 하향 방향도 함께 확인할 수 있습니다.

배경지도, 지형 표현 방식, 경사각 기준을 사용자가 직접 선택할 수 있도록 구성했기 때문에 목적에 따라 다양한 방식으로 지형을 탐색할 수 있습니다.

이러한 시각화는 다음과 같은 분야의 기초자료로 활용할 수 있습니다.

* 급경사지 및 산지 지형 탐색
* 도시계획과 개발 가능지역 검토
* 재해 취약지역의 예비 분석
* 산지와 주거지역의 공간적 관계 확인
* 지형 기반 교육 및 공간정보 시각화
* 상세 사면 분석 대상지역의 우선 선정
