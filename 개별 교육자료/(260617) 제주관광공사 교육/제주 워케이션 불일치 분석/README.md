# 제주 워케이션 인프라 공간적 불균형 분석 (QGIS)


## 분석 개요

2023년 제주연구원의 「제주지역 워케이션 활성화 방안」 연구에서는 워케이션 수요자가 선호하는 숙박시설과 공유업무시설 간 공간적 불일치가 존재하는 것으로 나타났다. 특히 제주도 외 소재하는 기업체를 대상으로 한 조사 결과, 호텔에 대한 선호도가 가장 높게 나타났으나 읍·면지역에서는 이러한 시설이 부족하여 접근성 측면의 한계가 확인되었다. 이에 본 분석에서는 제주시를 대상으로 공유업무시설과 숙박시설의 공간 분포 및 접근성을 분석하고, ORS 기반 네트워크 분석을 통해 공유업무시설과 호텔 간 공간적 불균형을 분석하고자 한다.  

*워케이션 : 단순 재택근무 및 원격근무와 달리 일과 관광 모두를 병행할 수 있는 새로운 근무형태

## 사용 데이터

| 데이터 | 제공 기관 |
|----------|----------|
| 숙박시설 현황 세부내역 (2026.04.30) | 제주특별자치도관광협회 |
| 공유업무시설 위치 정보 | 2026 제주 워케이션 안내 리플렛 |
| 제주도 1km 격자 경계 | SGIS 통계지리정보서비스 |
| 행정동 경계 | SGIS 통계지리정보서비스 |
| 시군구 경계 | SGIS 통계지리정보서비스 |
| 시도 경계 | SGIS 통계지리정보서비스 |


## 분석 과정
① 제주도 내 공유업무시설 및 숙박시설 위치 데이터 구축  
② 공유업무시설 및 숙박시설 공간 분포 현황 분석  
③ ORS 기반 공유업무시설 접근권역(Isochrone) 생성  
④ 공유업무시설과 호텔 간 네트워크 접근성 분석  
⑤ 공유업무시설과 호텔 간 공간적 미스매치 지역 도출
