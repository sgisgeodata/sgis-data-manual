# 제주 렌터카 체류 빈도 시각화 분석 (R)

## 분석 개요

본 분석은 2021년 제주 지역의 렌터카 체류 빈도 데이터를 활용하여  
렌터카 이용자가 제주도 내 어느 지역에 많이 머무르는지 50m 격자 단위로 시각화한 분석입니다.

월별로 제공된 렌터카 체류 빈도 데이터를 연간 단위로 합산하고,  
VISIT JEJU 여행장소 데이터를 함께 지도에 표시하여  
렌터카 체류가 많이 발생하는 지역과 주요 관광지의 공간적 관계를 확인할 수 있도록 구성했습니다.

최종 결과물은 확대·축소가 가능한 Leaflet 기반 HTML 지도로 제작했습니다.

---

## 활용 데이터

| 데이터 | 설명 |
|---|---|
| `체류빈도_2021_01.csv` ~ `체류빈도_2021_12.csv` | 2021년 월별 렌터카 체류 빈도 데이터 |
| `체류빈도_2021_합산.csv` | 월별 체류 빈도를 격자 단위로 합산한 연간 데이터 |
| `제주관광공사_제주관광정보시스템(VISIT JEJU)_여행장소.csv` | 제주 주요 여행장소의 위치 및 주소 정보 |

---

## 분석 과정

### 1. 월별 렌터카 체류 빈도 데이터 통합

먼저 2021년 1월부터 12월까지의 월별 렌터카 체류 빈도 CSV 파일을 불러왔습니다.

각 파일에는 50m 격자별 체류 빈도 정보가 포함되어 있으며,  
연간 체류 패턴을 분석하기 위해 12개월 데이터를 하나의 데이터로 통합했습니다.

---

### 2. 50m 격자 기준 연간 체류 빈도 합산

통합된 월별 데이터는 `j_50_cd`라는 50m 격자 코드를 기준으로 그룹화했습니다.

같은 격자에 해당하는 월별 체류 빈도를 모두 더해  
2021년 한 해 동안 각 격자에서 발생한 총 렌터카 체류 빈도를 계산했습니다.

이 과정을 통해 월별 데이터는 다음과 같은 연간 합산 데이터로 변환됩니다.

| 격자 코드 | 위치 좌표 | 2021년 총 체류 빈도 |
|---|---|---|
| `j_50_cd` | `left`, `right`, `top`, `bottom`, `xcoord`, `ycoord` | `체류빈도_2021` |

최종적으로 생성된 데이터는 `체류빈도_2021_합산.csv`로 저장했습니다.

---

### 3. 체류 빈도 구간화

체류 빈도 값을 지도에 바로 표현하면 값의 차이가 크기 때문에,  
분석에서는 체류 빈도를 일정한 구간으로 나누어 시각화했습니다.

체류 빈도가 없는 격자는 지도에서 보이지 않도록 투명 처리했고,  
체류 빈도가 높은 격자일수록 더 진한 색상으로 표현했습니다.

| 구간 | 지도 표현 |
|---|---|
| 0회 | 투명 |
| 1~10회 | 매우 낮은 체류 빈도 |
| 11~50회 | 낮은 체류 빈도 |
| 51~100회 | 보통 수준의 체류 빈도 |
| 101~250회 | 높은 체류 빈도 |
| 251회 이상 | 매우 높은 체류 빈도 |

---

### 4. 50m 격자 래스터 생성

격자별 체류 빈도 데이터를 지도 위에 효율적으로 표현하기 위해  
50m 해상도의 래스터 데이터를 생성했습니다.

각 격자의 중심 좌표를 기준으로 체류 빈도 구간값을 입력하고,  
제주 전역의 렌터카 체류 빈도 분포를 하나의 공간 데이터로 변환했습니다.

생성된 래스터는 `제주_렌터카_체류빈도_50m.tif` 파일로 저장했습니다.

---

### 5. VISIT JEJU 여행장소 데이터 처리

렌터카 체류 빈도와 관광지 위치를 함께 비교하기 위해  
VISIT JEJU 여행장소 데이터에서 위도와 경도 정보를 추출했습니다.

이후 제주 지역 범위에 해당하는 장소만 필터링하고,  
각 장소의 이름과 주소가 지도 팝업에 표시되도록 구성했습니다.

이를 통해 사용자는 지도에서 체류 빈도가 높은 격자와  
주요 관광지 위치를 함께 확인할 수 있습니다.

---

### 6. Leaflet 기반 인터랙티브 지도 제작

최종 시각화는 R의 `leaflet` 패키지를 활용하여 제작했습니다.

지도에는 다음 기능을 포함했습니다.

- 제주 렌터카 체류 빈도 50m 격자 표시
- VISIT JEJU 여행장소 위치 핀 표시
- 관광지명 및 주소 팝업 제공
- 밝은 지도 / 위성지도 배경 전환
- 체류 빈도 범례 표시
- 확대·축소 및 지도 이동 기능
- 레이어 표시 여부 선택 기능

최종 지도는 HTML 파일로 저장하여 브라우저에서 바로 확인할 수 있도록 했습니다.

---

## 분석 결과

분석 결과, 제주 전역의 렌터카 체류 빈도를 50m 격자 단위로 확인할 수 있었습니다.

색상이 진하게 표시된 지역은 렌터카 체류 빈도가 높은 지역이며,  
관광지 핀과 함께 살펴보면 주요 관광지 주변에서 렌터카 체류가 집중되는 경향을 확인할 수 있습니다.

특히 이 지도는 단순히 행정구역별로 집계한 결과가 아니라,  
더 세밀한 50m 격자 단위로 체류 빈도를 표현했기 때문에  
관광객 이동 및 체류가 집중되는 공간을 직관적으로 파악하는 데 유용합니다.
