# 🗺️ SGIS 공간정보 분석·활용 자료 저장소

**🌐 통계와 공간정보를 연결하고, 지역을 데이터로 이해하다**

국가데이터처 **통계서비스국 공간정보서비스과**의 공간정보 분석 사례, 교육·실습자료, 시각화 결과물 및 참고문헌을 공유하는 GitHub 저장소입니다. SGIS(통계지리정보서비스)의 소지역 통계와 행정구역·격자 공간정보를 활용하여 지역 현안을 탐색하고, R·Python·QGIS·웹 지도 등을 활용한 분석 과정을 학습·재현할 수 있도록 구성하였습니다.

**[🌐 저장소 바로가기 – SGIS 공간정보 분석·활용 자료](https://github.com/sgisgeodata/sgis-data-manual)** · **[🗺️ SGIS 바로가기](https://sgis.mods.go.kr/)** · **[📚 SGIS 개발지원센터](https://sgis.mods.go.kr/developer/)**

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **저장소명** | SGIS 공간정보 분석·활용 자료 저장소 (`sgis-data-manual`) |
| **운영·활용 분야** | 국가데이터처 통계서비스국 공간정보서비스과의 SGIS 공간정보 활용 및 교육·분석자료 공유 |
| **목적** | 소지역 통계와 공간정보를 결합한 분석 사례·교육자료·코드·시각화 결과물의 체계적 공유 |
| **주요 콘텐츠** | 지역별 공간분석 사례, 기관별 교육자료, 제주 렌터카 시각화, 교육환경 분석, SGIS 참고자료 |
| **주요 대상** | 공간정보 분석 담당자, 연구자, 지자체·공공기관 실무자, 교육생 및 SGIS 이용자 |
| **저장소** | [sgisgeodata/sgis-data-manual](https://github.com/sgisgeodata/sgis-data-manual) |

이 저장소는 특정 지역의 단일 분석 결과가 아니라 **다양한 분석 주제와 교육 과정을 함께 축적하는 통합 자료실**입니다. 동일한 주제가 분석 사례와 교육자료에 각각 포함될 수 있으며, 전자는 **분석 방법·코드**, 후자는 **교육 과정·실습 맥락**을 중심으로 탐색할 수 있습니다.

## 🛠️ 기술 스택 및 개발 환경

| 구분 | 기술·도구 | 주요 활용 내용 |
|---|---|---|
| **통계·공간분석** | R (`sf`, `terra`, `ggplot2`, `tmap`, `leaflet` 등) | 격자·행정구역 통계 분석, 주제도 제작, 인터랙티브 지도 |
| **데이터 처리·자동화** | Python, PyQGIS | 공간자료 가공, 반복 작업 자동화, 공간분석 스크립트 |
| **GIS** | QGIS | 공간자료 중첩, 도달영역·접근성 분석, 지도 제작 |
| **웹 시각화** | HTML, CSS, JavaScript, Leaflet | 분석 결과의 웹 지도 표현 및 레이어 전환 |
| **원격탐사·지형 분석** | Google Earth Engine, DEM 관련 도구 | 위성영상 시계열, 지표면 온도, 표고·경사 분석 |
| **공간 데이터 형식** | SHP, GeoJSON, CSV 등 | 행정경계, 격자통계, 시설 위치 및 분석 결과 저장 |
| **문서·배포** | Markdown, GitHub | 교육자료·분석 코드·사용 방법 기록 및 공유 |

## 🔍 분석 방법

1. **분석 주제 및 대상 지역 선정** — 인구구조, 교육서비스, 관광, 접근성, 지형·기후 등 분석 목적 설정
2. **통계·공간자료 수집** — SGIS 통계·경계, 시설 위치, 공공데이터 및 프로젝트별 자료 확보
3. **자료 전처리** — 좌표계·기준연도·행정구역 코드 정합, 결측·중복 확인, 공간자료 가공
4. **공간분석 및 통계 산출** — 공간 결합, 격자·행정동 집계, 시설 분포, 접근성, 변화 비교 등 주제별 분석
5. **시각화 및 결과 해석** — QGIS·R·Python 지도, 웹 지도, 도표 등을 활용한 결과 표현
6. **재현·공유** — 분석 코드, 실행 방법, 결과물 및 데이터 출처를 GitHub에 정리

※ 위 절차는 저장소 전반의 **공통적인 활용 흐름**이며, 각 사례의 실제 처리 순서·분석 기법은 해당 코드와 문서를 따릅니다.

## 🚀 이용 및 실행 방법

**① 저장소 탐색**

1. [저장소 메인](https://github.com/sgisgeodata/sgis-data-manual)에 접속합니다.
2. `공간분석 사례 Case Studies`에서 **분석 도구별 사례**를, `개별 교육자료 Training Materials`에서 **교육 과정별 실습자료**를 찾습니다.
3. 각 프로젝트의 `README.md`, `.R`, `.py`, `.html` 등 설명·코드·결과물을 확인합니다.

**② 자료 내려받기**

GitHub 저장소의 **Code → Download ZIP**으로 전체 자료를 내려받거나, 필요한 파일을 개별적으로 확인할 수 있습니다.

```bash
git clone https://github.com/sgisgeodata/sgis-data-manual.git
cd sgis-data-manual
```

**③ 분석 실행**

- **R 분석:** R/RStudio에서 `.R` 스크립트를 열고 필요한 패키지·입력 파일 경로를 설정합니다.
- **Python 분석:** Python 환경에서 `.py` 코드를 실행하며 의존 패키지와 데이터 경로를 확인합니다.
- **QGIS·PyQGIS:** QGIS 버전과 Processing 환경, 공간자료 경로를 확인합니다.
- **HTML 지도:** `.html`을 브라우저에서 열어 확인하되, 일부 결과물은 연결된 `lib/`, `*_files/` 등의 보조 파일이 함께 필요합니다.
- **GEE·API 실습:** 계정·인증키·데이터 접근 권한이 필요한 경우 별도 설정 후 실행합니다.

<details>
<summary><strong>💻 실행 전 확인사항 펼쳐보기</strong></summary>

1. 분석 코드에서 사용하는 **로컬 절대경로**를 본인 환경의 데이터 경로로 수정합니다.

4. CSV 문자 인코딩, 공간자료 좌표계, 통계·경계 기준연도를 확인합니다.
5. 일부 프로젝트는 원자료·외부 API·추가 라이브러리가 없어 그대로 실행되지 않을 수 있습니다.
6. 공개 코드에 인증키·개인정보·비공개 데이터를 포함하지 않도록 주의합니다.

## ⚠️ 분석의 한계 및 유의사항

- **기준시점의 차이:** 통계, 행정경계, 시설 위치, 교통·관광 데이터의 수집·갱신시점이 다를 수 있습니다.
- **공간단위의 차이:** 격자·행정동·시군구별 결과는 집계단위와 경계 설정에 따라 달라질 수 있습니다.
- **공개자료의 한계:** 비밀보호 처리, 결측·비공개 값, 원자료 미포함 등으로 결과 재현에 제약이 있을 수 있습니다.
- **접근성 분석의 가정:** 이동수단, 네트워크, 이동시간, 출입구 위치 등의 설정에 따라 도달영역이 달라집니다.
- **시각화와 인과관계:** 지도에서 확인한 공간적 중첩·상관관계만으로 원인과 결과를 단정할 수 없습니다.
- **교육용 코드의 특성:** 일부 코드는 특정 교육 시점·환경에서 작성된 실습용으로, 실행 전 경로·패키지·API 상태 점검이 필요합니다.
- **저장소 변경 가능성:** GitHub 폴더·파일·커밋 구성은 수시로 변경될 수 있으므로 최신 버전을 확인해야 합니다.
